## 一、产品定位

### 1.1 核心定义
> **Assista 是 AI 操作系统，一片广袤的大地。**

不是聊天机器人，不是命令行工具，不是单一功能应用。

Assista 提供基础能力，让用户和开发者在这片大地上创造无限可能。

### 1.2 与竞品的本质区别

| 产品 | 定位 | 局限 |
|------|------|------|
| OpenClaw | 个人助理框架 | 配置复杂、易崩、上下文管理弱 |
| ChatGPT | 对话模型 | 无本地能力、无记忆、无工具 |
| Raycast | 启动器 | 无 AI 决策、扩展门槛高 |
| **Assista** | **AI 操作系统** | **本地执行 + LLM 决策 + 无限扩展** |

### 1.3 四大核心维度

```
Assista 能力 = 模型能力 × 上下文工程 × 记忆系统 × 工具边界
```

| 维度 | 作用 | V3.3 状态 |
|------|------|----------|
| **模型能力** | 智力上限 | ✅ Kimi k2.5，可扩展多模型 |
| **上下文工程** | 激发潜力 | ✅ AGENTS.md / SOUL.md / 动态组装 |
| **记忆系统** | 持续进化 | ✅ 创建/遗忘/压缩/长期记忆 |
| **工具边界** | 触及万物 | 🔄 基础工具，GUI/MCP 待 V3.4+ |

### 2.2 核心模块

#### 上下文工程（V3.3 核心创新）

**AGENTS.md - 启动协议**
```markdown
每次对话开始，严格执行：
1. 读取 SOUL.md - 理解自己是谁
2. 读取 USER.md - 理解用户是谁
3. 读取 memory/YYYY-MM-DD.md - 了解今天发生了什么
4. 主会话时读取 MEMORY.md - 了解长期记忆
5. 读取 TOOLS.md - 了解可用工具
```

**SOUL.md - 人格定义**
- 身份、使命、愿景
- 性格、价值观
- 能力边界
- 行为模式

**记忆分层**
- 工作记忆：当前会话（内存）
- 短期记忆：每日文件（memory/YYYY-MM-DD.md）
- 长期记忆：精选记忆（MEMORY.md）

#### 记忆系统（V3.3 实现）

**创建记忆**
- 自动提取：用户偏好、重要决策、项目信息
- 手动记录：用户说"记住"
- 工具执行：重要操作记录

**遗忘机制**
- 用户主动遗忘：`遗忘 关键词`
- 自动清理：30天过期 + 容量上限
- 防误删：重要性评分 + 关键词保护

**智能压缩**
- 保留最近 10 轮完整对话
- 更早对话压缩成 2-3 句摘要
- LLM 自动生成摘要

## 四、开发规范

### 4.1 架构决策记录（ADR）

**ADR-001: 上下文工程模式**
- **状态**: 已接受
- **决策**: 采用 OpenClaw 的 AGENTS.md 模式，分层加载上下文
- **原因**: 精准控制 LLM 可见信息，避免上下文污染，支持人格定义

**ADR-002: 记忆遗忘机制**
- **状态**: 已接受
- **决策**: 重要性评分 + 关键词保护 + 用户主动遗忘 + 自动清理
- **原因**: 模拟人类记忆，保留重要信息，自动清理噪音

### 4.2 代码规范

- 接口契约优先（AgentInput/Output, ToolInterface）
- 异步非阻塞（async/await）
- 错误分类处理（ErrorCategory）
- 类型提示（typing）

## 五、使用指南

### 5.1 快速启动

```bash
cd ~/Desktop/Assista_V3/V3.3_开发版
python3 Assista-V3.3.py
```

### 5.2 自定义人格

编辑 `workspace/SOUL.md`，定义 Assista 的身份、性格、能力边界。

### 5.3 记忆管理

- `记住 XXX` - 让 Assista 记住信息
- `遗忘 XXX` - 删除相关记忆
- `清理记忆` - 自动清理过期记忆

### 5.4 工具使用
